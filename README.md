# Expense Tracker

A simple command-line expense tracker built with Python, pandas, and matplotlib.
Log your spending, then see totals and charts by category and month.

## Setup

```
pip install -r requirements.txt
python tracker.py
```

## Features

- Add expenses (category, amount, note)
- Saves to `expenses.csv`
- Report with totals per category and per month
- Saves charts as `report.png`
